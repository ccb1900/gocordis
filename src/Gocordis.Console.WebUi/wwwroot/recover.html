Gocordis host recovery

The web transport, control API and plugin store are host infrastructure and remain available when the optional console UI plugin is missing, disabled or being upgraded.

To restore the last known-good application declaration:

POST /api/host/recover  { "source": "recovery-page" }

Or from the CLI (it uses the same HTTP control plane):

gocordis console restore --address <host-url>

To reinstall or replace the console UI plugin, use:

gocordis console restore <package.gocordis-plugin> --address <host-url>
